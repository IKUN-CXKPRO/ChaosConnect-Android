# ChaosConnect 0.5.0 验证

本轮交付使用仓库既有的 AGP 9.4.1，未混入工作区的 AGP 降级。完整 Android 构建、lint、27 项 JVM 测试和 12 项模拟器仪器测试通过，全部 0 跳过/失败。5 项生产 C/Kotlin 互通包括 NSH 分帧与手环撤权；PTY 是显式 echo seam，不是实体手环执行证明。

- 五项底栏：主页、文件管理、终端、连接、我的，悬浮/原生底栏和两套 UI 都覆盖。

- 手环：31 项协议/权限回归，独立 CCN1 和网页 PTY 引擎各 27 项；原 .043 PTY 11 项与 spawn 探针通过，完整安装包/ELF 校验通过。
