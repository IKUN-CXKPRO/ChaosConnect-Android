# 安装投递包

Android 0.6.0：功能列表 → 顶部“安装投递包” → 选择 Chaos 制作台输出的 `.bin` → 核对名称 → 安装。

先连接并在手环确认 ChaosConnect 本次连接。手机弹窗为“是否安装投递包：名称”，手环默认还会亮屏、震动并显示“是否允许Android端安装投递包：名称”。两端使用包在 Chaos 字体／图标清单中的最终短名，不使用文件名。

手环 ChaosConnect → 权限设置 → Android端权限新增“安装资源包”，可选开启／关闭／询问，默认为询问。安装不依赖通用文件写入、开发者模式或 NSH 权限，关闭安装权限会中止任务。需要配套新版 Chaos（HELLO 安装能力位 `0x20`），旧版模块会提示更新。

读取与安装均在后台，提供进度、取消和错误提示。文件先复制到应用私有缓存，校验 10 Pro 容器布局，再提取字体或 CIPK 图标资源。包内 Lua 只解析最终名称，不执行；包附带的模块、应用图标、预览不会写到手环。数据按协商块／窗口传输，逐文件及整体 CRC32 校验。全部完成才发布清单，避免安装中断破坏现有资源。

安装后到 Chaos 的字体／图标包列表选择。当前同名包和槽位不足会拒绝，需先在 Chaos 中删除旧包。上限：容器48MiB、资源32MiB、图标256个；字体／图标各沿用手环8槽。安装过程中修改手环清单会使提交被拒绝，需要重新开始。

## 验证

JVM 测试包含生产网页版构建器生成的合成容器，校验布局损坏、固定槽路径与最终名称；生产 Kotlin/C 互通覆盖字体／图标安装、独立授权、拒绝和取消、最终数据与清单一致。测试包中的 Lua／模块／图像均为明确合成数据，不是可用的主题素材。两套界面的模拟器测试覆盖入口、确认名称、取消、安装进度以及返回；没有声称完成实体无线安装。
