# 连接测速

入口：**我的 → 设置 → 连接测速**。先连接手环并完成连接授权，再点击“开始测速”。

开始后持续传输，没有测试时长或数据量上限；点击“停止测速”结束。应用内切换页面不会停止，返回测速页可继续查看。断开连接、连接被撤销、通信错误或应用进程结束时停止。再次开始会清零本次统计。

## 测量方式

- 通过当前真实 CCN1 连接执行 `ECHO (0x31)`，使用手环协商的 chunk 与窗口，最多同时等待 8 个应答。
- 先回显最多 32 字节预热，预热不计入结果；每个测试数据块校验返回字节，错误的数据不计入速度。
- 显示 `KiB/s`（1 KiB = 1024 字节）、已校验的发送／接收字节数与耗时。速度是从预热后开始的平均有效载荷速率，不把收发相加翻倍；包含往返等待，不能当作单向无线带宽上限。
- 不创建、读取或写入手环文件，不需要文件写入、开发者模式或 NSH 权限。
- 统计每约 200ms 刷新，计数与耗时使用 64 位数；队列容量固定，不随测试时间增长。

## 持续传输与停止

ECHO 与只读连接状态轮询使用独立的 8 个循环请求编号，不占用文件操作的单次编号，持续测速不会在发送 65535 个回显请求后中断。副作用操作的请求编号仍不复用，原有会话前缀、应答操作码匹配与数据校验保持有效；异常操作不会自动重发。

点击停止后不再提交数据，已提交的一小窗口由连接完成。取消 socket 的半条记录会破坏后续帧，因此不会强制截断正在写入的记录，包括预热写入。停止不会主动断开蓝牙。

## 验证边界

测试覆盖超过旧 30 秒、8 MiB 和 65535 个回显请求限制后仍持续运行，手动停止、预热／传输中取消、数据损坏以及生产 C 文件引擎回显互通。模拟器只验证界面和流程。主机互通的速度不是实体无线速度；实际结果需要手机连接手环后在本页测试。
